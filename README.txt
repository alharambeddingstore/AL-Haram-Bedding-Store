# AL HARAM Bedding Store — Free Website Starter

This is a static, mobile-friendly demo website. It is not published yet and does not collect online payments.

## Preview on a computer
1. Unzip the folder.
2. Open `index.html` in a web browser.

## Before taking real orders
1. Open `index.html` in a text editor.
2. Find `const WHATSAPP_NUMBER = "92XXXXXXXXXX";`
3. Replace it with your Pakistan WhatsApp number including country code, digits only, e.g. `923001234567`.
4. Edit the `products` list in the script: product name, category, price, description and image URL.
5. Replace the sample images and prices with your own real product details.
6. Confirm delivery charges, returns, privacy/contact details before launch.

## Publish free with GitHub Pages
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. `al-haram-bedding-store`.
3. Upload `index.html` to the repository root.
4. Open repository **Settings → Pages**.
5. Under build/deployment, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
6. Wait for GitHub to show the published `github.io` URL in Settings → Pages.

GitHub Pages may take a few minutes to publish. The exact menu wording can change. Keep in mind: a public GitHub Pages website is visible to anyone who has the link and is a static site.

## Important limitations
- The product list and demo cart are front-end only. There is no secure admin login or shared product database.
- The WhatsApp order button will work only after you add your correct number.
- No card payments, COD integration, shipping integration, real order database, or stock synchronization is included.
- For editing product listings on a public site, edit `index.html` in GitHub and commit the changes. For an admin panel where products can be added from a phone and instantly appear for every customer, connect a backend/database or e-commerce platform later.
- Use your own licensed photos or product images you have permission to use.
